# Configuration Reference

## timeout
The default timeout is 60 seconds. Use `--timeout <seconds>` to change it.

## retries
Failed tasks are retried 3 times by default. Use `--retries <n>` to change it.

## logLevel
The default log level is info. Use `--log-level <level>` to change it.

## outputFormat
Output is printed as json by default. Use `--format <name>` to change it.

## legacyMode
Pass the `--legacy-mode` flag to switch to the old scheduler. It is disabled by default.
